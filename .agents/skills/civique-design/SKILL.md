---

# Design principles

- Create a friendly, playful and motivating learning experience.
- Use Duolingo as inspiration, not as a direct visual copy.
- Avoid generic SaaS dashboard aesthetics.
- Prioritize mobile-first responsive design.
- Use original illustrations and brand characters.

# Visual identity

- Primary color: #2563EB
- Success color: #58CC02
- Error color: #FF4B4B
- Reward color: #FFC800
- Background color: #F7F8FA
- Text color: #243247
- Font family: Nunito
- Border radius: 12–20px
- Use generous spacing and clear typography.

# Components

- Tactile buttons with bottom borders.
- Large interactive answer cards.
- Rounded progress bars.
- Friendly feedback panels.
- Learning path nodes.
- Achievement cards.
- Category illustrations.

# Quiz experience

- Display one question at a time.
- Make answer options large and easy to select.
- Provide immediate visual feedback in training mode.
- Use short, supportive explanations.
- Preserve a consistent layout between questions.
- Use subtle animations for transitions and feedback.

# Exam experience

- Use a focused and distraction-free interface.
- Disable hints and immediate correctness feedback.
- Display remaining time and question navigation.
- Avoid gamification during the examination.

# Technical requirements

- Nuxt, Vue, TypeScript and Tailwind CSS.
- Reusable UI components.
- Centralized design tokens.
- Accessible keyboard navigation.
- WCAG AA color contrast.
- Respect prefers-reduced-motion.
- Separate UI components from business logic.

# Restrictions

- No unnecessary gradients.
- No excessive shadows.
- No glassmorphism.
- No excessive decorative cards.
- Do not copy Duolingo branding, illustrations or mascot.
- Do not introduce new colors outside the design system without justification.
